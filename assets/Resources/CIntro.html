Literal suffixes

Number literals default to int and double. Tell the compiler otherwise:

3.5f float · 19.99m decimal · 9000000000L long · 25u uint

Value vs. reference

Value types hold the data itself and copy on assignment. Reference types hold an address that points at data on the heap — copying the variable copies the address, not the object.

Default values

Uninitialized fields start at 0 for numbers, false for bool, '\0' for char, and null for reference types. Local variables must be assigned before use.

Converting text to numbers

User input arrives as string. Use int.TryParse or double.TryParse so bad input returns false instead of crashing.
