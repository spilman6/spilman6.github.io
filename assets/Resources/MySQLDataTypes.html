Signed vs. unsigned

Integer types are signed by default. Add UNSIGNED when negatives are impossible; it doubles the positive range.

Display width is not size

INT(11) does not store an 11-digit number. In modern MySQL, the display width is deprecated. Use INT.

Character sets

Use utf8mb4 for modern Unicode text, including emoji. A VARCHAR(100) limit is characters, while storage varies by encoding.

NULL and defaults

NULL means unknown or missing, not an empty string or zero. Make required columns NOT NULL and choose defaults deliberately.
