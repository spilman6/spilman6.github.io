Printable ASCII reference

The ASCII map

Letters, lowercase letters, digits, spaces, and punctuation all have a decimal code and an 8-bit binary representation.

ASCII covers standard English characters. Most modern text uses Unicode, which builds on the same idea with a much larger character set.
