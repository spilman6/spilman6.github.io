Binary fundamentals

Learn Binarybit by bit.

An 8-bit binary number has eight places. Enter a 1 to include a value or a 0 to leave it out. Your selected places add up to the target decimal number.

How it works

Each position represents a power of two. A 1 turns that value on; a 0 leaves it off.

Quick check
Start with the largest place value that does not go over the target. Subtract it, then continue to the right.
